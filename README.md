# さとるエディタ

Mac 用の軽いテキストエディタです。Windows の定番エディタの使い心地を目指し、日本語のテキストやプログラムを手早く編集できるように作っています。

- タブで複数のファイルを開ける（タブバーは常に表示、右端の ＋ で追加）
- 行番号、桁ルーラー、改行・タブ・全角スペースの記号、[EOF] の表示
- 文字コードの自動判定（UTF-8 / Shift_JIS / EUC-JP / JIS / UTF-16）。新規ファイルは UTF-8
- 改行コード（LF / CRLF / CR）を保ったまま保存
- 言語ごとの色分けとタブ幅（Swift, Python, JavaScript/TypeScript, Go, Rust, C/C++, Java/Kotlin, Ruby, PHP, シェル, HTML/XML, CSS, JSON, YAML, SQL, Markdown など 18 種類）
- 検索バー、正規表現の置換、grep（フォルダ内検索とタグジャンプ）
- ウインドウの上下分割
- 行の複製・削除・移動、インデント、コメント切り替え、並べ替え、重複行の削除
- テーマ 8 種類（ダーク・ライト・暖色・ピンクなど）。設定画面の見本（小さなエディタ画面）をクリックして切り替え。色・フォントの細かい変更も可
- アプリのアイコンの色を 8 色から選べる（藍・朱・ひのき緑・墨・山吹・紫・浅葱・生成り）
- 印刷（⌘P）。PDF として書き出すときと同じ見た目で刷る。作文用紙モードでは横向きの紙にマス目つきで刷る
- PDF / Word (.docx) への書き出し、PDF からテキストの読み込み
- キー割り当て、メニュー編集、ツールバー編集
- ファイルの関連付けと Finder の右クリックメニュー（「さとるエディタで開く」「さとるエディタで grep」）
- 設定内容の保存・復元
- 共同編集: 「IP アドレス:ポート」と共有コードを伝え、承認した相手と同じ文書を同時に編集。相手のカーソル (PC 名つき) とチャット。通信は暗号化 (既定ではオフ。「共有 > 共有機能を使う」でオン)
- サーバ (SFTP / FTP / FTPS): 登録したサーバの中を見て回り、ファイルを開いて編集。保存するとサーバへ反映 (入力が止まって 2 秒後に自動反映も可)。パスワードはキーチェーンに保存
- 流出防止 (既定でオン): 文書を暗号化ファイル (AES-256-GCM) として保存。暗号化していない文書を保存するときは「暗号化して保存 / そのまま保存」を聞く。暗号化の方法は 6 通り (下の表)。暗号化した文書はタイトルとタブに 🔒 が付く
- 用紙モード: 作文用紙 (縦書き 400 字詰め) や A4 用紙の見た目で書ける
- AI アシスタント: 校正・要約・続きを書くなどを横の欄から頼める
- フォルダツリー: フォルダの中身を左にツリーで表示。クリックでタブに開く、ファイル名で絞り込み、右クリックで新規・名前変更・ゴミ箱など

共同編集・サーバ・流出防止・用紙モード・AI アシスタント・フォルダツリーは「追加機能」です。「設定 > 追加機能」かメニューバーの「追加機能」でオン・オフでき、オフの機能はメニューやツールバーに出ません。オンにすると、その機能がすぐ画面に出ます (AI は横の欄、用紙モードは作文用紙、サーバはサーバの設定画面、フォルダツリーは左のツリー)。

対応 OS: macOS 11 Big Sur 以降（Apple Silicon と Intel の両方）

## インストール

1. `SatoruEditor-1.0.0.dmg` を開き、「さとるエディタ」を「Applications」フォルダへドラッグします。
2. 初めて起動するときは、アプリを **右クリック →「開く」** を選び、確認画面で「開く」を押します。

Apple の公証（notarization）を受けていないため、普通にダブルクリックすると「開発元を確認できない」と表示されます。上の手順は初回だけで、2 回目からは普通に起動できます。

「壊れているため開けません」と表示されたときは、ターミナルで次を実行してから開いてください。

```sh
xattr -dr com.apple.quarantine "/Applications/さとるエディタ.app"
```

## 設定

メニューバーの右端の「設定」から開きます。

| タブ | 内容 |
|---|---|
| 動作環境 | 折り返し、記号の表示、行番号、行の数え方、自動インデント、新規ファイルの文字コード、保存時のバックアップなど |
| ファイルタイプ別の設定 | 拡張子、タブ幅、コメント記号、キーワードなど。自分で言語を追加することもできます |
| 色・フォント | テーマの切り替え (見本をクリック)、アプリのアイコンの色、21 項目の色・フォントの変更 |
| 追加機能 | 機能ごとのオン・オフと説明 (開閉できる段)。流出防止では、最初に選ばれる暗号化の方法も選べる |
| キー割り当て | メニューのすべての項目のショートカット |
| メニュー編集 | 使わないメニュー項目を隠す |
| 関連付け | 拡張子ごとに「さとるエディタで開く」設定、Finder の右クリックメニュー |

「設定内容の保存…」で全部の設定を 1 つのファイルに書き出し、別の Mac で「設定内容の復元…」で読み込めます。

設定ファイルは `~/.satomaru/` にあります（`theme.json` と `profiles.json`）。テキストで直接編集することもできます。

## 共同編集・サーバ・暗号化について

- **共同編集**は、共有のたびに作られる 16 文字の共有コードで通信を暗号化します (ChaCha20-Poly1305)。コードを知らない相手は承認の確認まで進めません。初回は macOS のファイアウォールが接続の受け入れを確認することがあります。
- **SFTP** は macOS の OpenSSH、**FTP/FTPS** は macOS の curl を使います。SFTP で初めてつなぐサーバの鍵は自動で登録し (`~/.satomaru/ssh/known_hosts`)、あとで変わったときは接続を止めます。FTP は暗号化されないので、できれば SFTP か FTPS を使ってください。
- **暗号化ファイル**の方法は次の 6 通りです。暗号化する前の平文のファイルがディスクのどこかに残っている可能性はあるので、大事なものは最初から暗号化して保存してください。

| 方法 | 開くのに要るもの | 別の Mac で開けるか |
|---|---|---|
| パスワード (8 文字以上) | パスワード | 開ける |
| パスコード (数字 6 桁以上) | パスコード | 開ける |
| この Mac のロック | Touch ID か Mac のパスワード | 開けない |
| ワンタイム認証 | スマホの認証アプリに出る 6 桁 | 開けない |
| 二段階 | パスワード + スマホの認証アプリの 6 桁 | 開けない |
| 鍵ファイル | USB メモリなどに置いた鍵ファイル | 開ける |

パスワードとパスコードはどこにも保存されません。忘れると開けなくなります。「この Mac のロック」「ワンタイム認証」「二段階」は鍵 (の一部) をこの Mac のキーチェーンに置くので、暗号化した Mac でしか開けません。ワンタイム認証は、初回に出る設定キーを控えておくと新しいスマホに登録し直せます。鍵ファイルは、なくすと開けなくなるので控えを別の場所にも置いてください。挿してあるディスクのいちばん上の階層にあれば自動で見つけます。

## ソースからビルド

Xcode（またはコマンドラインツール）と Swift 5.5 以降が必要です。

```sh
swift test                         # テスト
./scripts/bundle.sh                # この Mac 用の build/さとるエディタ.app
./scripts/bundle.sh --universal    # Apple Silicon と Intel の両対応
./scripts/bundle.sh --dmg          # 両対応でビルドして配布用の DMG も作る
```

アイコンは `./scripts/make_icons.sh` で作り直せます (既定のアイコンと、設定で選べる色ちがい 8 色)。絵は `scripts/make_icon.swift` にあります。
