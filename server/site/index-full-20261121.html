ぜんぶサクサク、ひとつのエディタで。

さとるエディタは、編集・管理・共有がかんたんにできる総合テキストエディタです。ふつうのエディタ・原稿用紙・A4 用紙を切り替えて書けて、書いたテキストは一覧でまとまり、保存のたびに版の履歴が残ります。AI アシストや読み上げも使えて、できた文章はリンク 1 つで公開できます。

⬇ ダウンロード 無料 リンクで公開共有について GitHub (ソース)
EDIT編集

行番号つきのエディタ、原稿用紙、A4 用紙。書くものに合わせて、ボタン 1 つで切り替え。

 MANAGE管理

書いたものは一覧にまとまり、保存のたびに版の履歴が残ります。前の版との違いもひと目で。

 SHARE共有

「リンクで公開共有」で、そのままの見た目で Web に。公開したあとの更新や変更の履歴も残せます。
EDIT

書くものに合わせて、画面ごと切り替える。

ツールバーの「用紙切替」で、同じテキストを 4 つの画面で書けます。どの画面で書いていたかはファイルに覚えておくので、次に開いたときも同じ画面です。切り替えに出す画面は、設定で選べます。

行番号・改行の印つきの、軽いエディタ。メモやコードにも。

標準エディタ

メモも、議事録も、コードも。軽くてすぐ書ける、行番号つきのエディタです。

  • 行番号・桁のものさし・改行や空白の印
  • 正規表現の検索と置換、差分の表示
  • ウィンドウの分割、ウィンドウの並べ替え
  • 色・文字・キー割り当てを好みに

原稿用紙 (縦書き・横書き)

作文・読書感想文・小説の下書きに。マス目の上で 1 文字ずつ書けます。

  • 漢字に自動でふりがな (マスにそろえて表示)
  • 題名・名前・段落の下げを自動で整える
  • 枚数・何列何マスかをいつでも表示
  • 原稿用紙のまま PDF や画像に

AI アシスト

画面の右はしのタブを押すと、横からすっと出てきます。書きながら、そのまま頼めます。

  • 校正・要約・読みやすく・翻訳・続きを書く などを「…」から選ぶだけ
  • 答えは本文に、打ちこむようにすばやく反映 (⌘Z で戻せる)
  • 欄は別のウィンドウに取り出すことも。× で元の場所に戻る
  • ChatGPT・Claude・Gemini や、手元で動かす AI (ローカル LLM) も
読み上げ

書いた文章を声で読み上げて推敲。最初はパソコンの標準の声で、VOICEVOX の声もワンクリックで使えます。

A4 用紙

A4 のレイアウトで書いて、そのまま印刷・PDF に。

データ暗号化

パスワードをかけて保存。大事なテキストも安心です。

サーバ (SFTP / FTP)

サーバーのファイルを直接開いて編集・保存。ファイルツリーで辿れます。

スクショ

見えている画面や原稿用紙全体を、画像にしてすぐ共有。

追加機能

使う機能だけをオンに。それぞれのメニューから、すぐ設定へ。

MANAGE

保存を気にせず書いて、一覧でサッと探す。

左にテキストの一覧とフォルダ。更新した順に並び、保存のたびに版の履歴が残ります。一覧は上下 2 段・左右 2 列をボタンで切り替えられます。

テキスト一覧

  • ファイル名と拡張子 (txt・html など)、フォルダ、「5 分前」のような更新の時間がひと目でわかる
  • 原稿用紙・A4・エディタの印、公開中のものにはリンクの印
  • 好きな場所のフォルダを開いて、そのまま一覧に
  • ⇧ や ⌘ でいくつも選んで、まとめて削除・移動
  • 右クリックで ピン固定・ロック・複製・移動・版の履歴
  • サムネで並べて見わたすことも

版の履歴

保存するたびに、その時の中身を版として残します。うっかり消しても、前の版に戻せます。

  • Word のように、消したところは赤い取り消し線、足したところは青い下線で
  • 好きな版を見る・コピーする・その版に戻す
  • 残す数は設定で (はじめは 20 個)。開いただけでは増えません
  • Finder でファイルを動かしても、履歴はついてきます
  • 一覧と履歴は、パスワードをかけてまるごとバックアップ
  • 版の履歴
  • 違いを Word 風に
  • フォルダのツリー
  • 好きなフォルダを開く
  • ピン固定
  • ロック
  • 検索
  • サムネ表示
  • まとめて削除
  • パスワード付きバックアップ
  • ふつうのテキストファイルのまま
SHARE

リンク 1 つで、そのままの見た目で公開。

「公開 > リンクで公開共有」を押すと、文章をインターネット上に公開して URL を発行します。勝手に一覧に載ることはありません。原稿用紙は原稿用紙のまま、エディタはあなたの色と行番号のまま。URL を送るだけで、だれでも読めます。

だれに見せるかを選べる

  • 公開 … URL を知っていればだれでも読め、検索にも出ます
  • リンクを知っている人だけ … URL を送った人だけ
  • パスワード … パスワードを入れた人だけ
  • 公開の期限は日時まで細かく。あとから設定を変える・いつでも公開をやめる
  • 公開する前に、電話番号や住所などの個人情報が入っていないか確かめる
  • 直したらページを更新。変更の履歴と、どこが変わったかも見せられる
  • ページでは、ずんだもんの声で 1 行ずつ読み上げ・テキストや画像でコピー・用紙の切り替え
  • SNS に貼ると、中身が見えるカード画像つき

うっかり公開を防ぐ

公開する前に、電話番号・住所・メールアドレス・名前・パスワードらしいものが入っていないかを、パソコンの中だけで確かめます。見つかったら、公開する前に知らせます。

  • 「やめて見直す」で、見つかったところを選んだ状態にして戻る
  • 確かめた内容は、どこにも送りません
