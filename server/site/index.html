FEATURES

できること

エディタ表示

行番号つきの軽いエディタ。書いたものは一覧にまとまり、版の履歴も残ります。

原稿用紙

縦書き・横書き・A4 にボタン 1 つで。ふりがなや段落の下げも自動。

AI 補正 実験中

誤字直し・要約・続きを書く などを、横から出る欄で頼めます。

共有機能 実験中

URL ひとつで、そのままの見た目で公開。見本を見る

用途に応じたカスタマイズ

使う機能だけをオンにして、色・字・キー・メニューも自分好みに。メモ用にも、作文用にも、仕事用にも、自分に合ったエディタにできます。

画面を押すと、次の設定に切り替わります。
