書く・まとめる・共有する。
みんなの声で育てていくエディタ。

さとるエディタは、ふつうのメモから作文・原稿まで、ひとつで書けるテキストエディタです。いまは β テスト版。使ってくれた人の意見をもとに、少しずつ良くしていきます。

🧪
まだ実験中のアプリです。 機能や見た目は、みなさんの意見でどんどん変わります。不具合があるかもしれないので、大事な文章はバックアップを取りながら使ってください。
FEATURES

できること

同じ文章を、ボタン 1 つで 4 つの画面に切り替えて書けます。

行番号・改行の印つきの、軽いエディタ。メモやコードにも。

✍️ 書く画面を切り替え

ふつうのエディタ・原稿用紙 (縦・横)・A4 用紙。原稿用紙は、ふりがなや段落の下げも自動で。

🗂 一覧で、サッと探す

書いたテキストはフォルダごとに一覧に。ファイル名・場所・更新の時間がひと目でわかります。

🕘 版の履歴

保存するたびに版を残します。前とどこが変わったかを見て、前の版に戻すこともできます。

✨ AI アシスト実験中

右はしのタブを押すと、横から AI の欄が出てきます。校正・要約・続きを書く などを頼めます。

🔗 リンクで公開共有実験中

文章をインターネットに公開して URL を発行。原稿用紙は原稿用紙のまま。公開前に個人情報がないかも確かめます。

🔊 読み上げ実験中

書いた文章を声で読んで、推敲に。(Mac 版)

ほかにも、サーバのファイルの編集・データ暗号化など。使う機能だけをオンにできます。

BETA

β テストについて

さとるエディタは、作りながら、使ってくれた人といっしょに育てていくアプリです。

  1. まずは使ってみてください。 無料で、Mac でも Windows でも使えます。
  2. 気づいたことを教えてください。 「ここが使いにくい」「こんな機能がほしい」「動かない」など、ひとことで大丈夫です。
  3. 意見をもとに、改善していきます。 新しい版が出たら、アプリが自動で知らせて、そのままアップデートできます。
